# Ventorea Studios Bot

A Discord.js v14 bot for moderation, warnings, automatic timeouts, welcome messages, support tickets, slash commands, AI chat, audit logs, embeds, announcements, and member verification.

## Requirements
- Node.js 20+
- A Discord application and bot token
- Optional Gemini API key for AI chat

## Setup
1. Create an application at https://discord.com/developers/applications.
2. Add a Bot user and copy its token. Never share or commit the token.
3. Under OAuth2 > URL Generator, select `bot` and `applications.commands`.
4. Grant only needed permissions: View Channels, Send Messages, Embed Links, Read Message History, Manage Channels, Moderate Members, Kick Members, Ban Members, Manage Messages, and Manage Roles. Keep the bot role below administrator roles.
5. Invite the bot to your server using the generated URL.
6. Copy `.env.example` to `.env` and fill in the values.
7. Install and start:
   ```bash
   npm install
   npm run register-commands
   npm start
   ```

## Configure IDs
Enable Developer Mode in Discord, right-click the server/channels/roles, and choose Copy ID.
- `GUILD_ID`: your server ID, used for fast command registration during setup.
- `WELCOME_CHANNEL_ID`: optional welcome channel.
- `LOG_CHANNEL_ID`: optional moderation/audit log channel.
- `TICKET_CATEGORY_ID`: optional category for private support tickets.
- `VERIFIED_ROLE_ID`: optional role assigned by the `/verify` command.
- `STAFF_ROLE_ID`: optional role allowed to use staff-only actions and view tickets.

## Commands
- `/ping`, `/help`
- `/warn`, `/warnings`, `/timeout`, `/kick`, `/ban`, `/clear`
- `/ticket-panel`, `/close-ticket`
- `/verify`
- `/announce`
- `/embed`
- `/ask` (requires `GEMINI_API_KEY`)

Warning policy: the bot records warnings in its local SQLite database. The third warning applies a 1-hour timeout, the sixth warning applies a 5-hour timeout, and the ninth and later warnings apply a 24-hour timeout. Staff can still use Discord's native moderation controls. Tune this policy in `src/index.js` before inviting the bot to a large server.

## Cloud hosting
Deploy this folder as a Node.js worker on a host such as Railway or Render. Set every `.env.example` variable in the host's environment settings. Use persistent storage for `data/bot.sqlite` or move the database to a managed database; ephemeral filesystems erase local SQLite data on redeploy. Keep the process running continuously. Register slash commands after changing command definitions.

## Safety and operations
- Never put bot tokens or AI API keys in frontend code or GitHub.
- Keep privileged Gateway Intents disabled unless the bot needs them.
- Use a dedicated log channel with restricted access.
- Test moderation and ticket permissions in a private test server first.
- AI replies are generated by an external model and should not be treated as authoritative.
